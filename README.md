# Premium Digital Business Card

A responsive, interactive business card for Aashish Yadav, built with semantic HTML, modern CSS, and vanilla JavaScript.

## Features

- Premium dark glassmorphism-inspired design
- Responsive layout for desktop and mobile screens
- Interactive 3D card flip
- Contact links for email and phone
- GitHub and LinkedIn profile links
- Copy-email button with confirmation feedback
- Availability status indicator
- Reduced-motion support for accessibility
- No frameworks or build tools required

## Project structure

```text
Business Card/
├── index.html       # Card markup
├── style.css        # Responsive visual styles
├── script.js        # Flip, swipe, copy, and pointer interactions
└── assets/
    └── aashu.png    # Profile image
```

## Run locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

For the best development experience, serve the folder with a local server such as the VS Code Live Server extension.

## Customize

Update the following values in [index.html](./index.html):

- Name, role, and location
- Email address and phone number
- GitHub and LinkedIn URLs
- Profile image path and alt text

The primary colors, typography, layout, and responsive breakpoints can be adjusted in [style.css](./style.css).
